# Классификация данных и инструменты защиты

## Критические данные

| Категория данных | В чём необходимость защиты | Инструменты защиты |
|-|-|-|
| **Паспортные данные** | Идентификационное мошенничество, кража личности, открытие кредитов | **Хранение:** AES-256, отдельное зашифрованное хранилище<br>**Передача:** TLS 1.2+<br>**Доступ:** Ограничен ресепшеном (при необходимости)<br>**Индекс:** Хешировано (SHA-256) для поиска<br>**Удаление:** Автоматически через 5 лет<br>**Аудит:** Audit log всех обращений |
| **СНИЛС / ОМС / ДМС** | Идентификационное мошенничество | **Хранение:** AES-256, отдельное зашифрованное хранилище<br>**Передача:** TLS 1.2+<br>**Доступ:** Передача только ФОМС<br>**Маскирование:** Показывать только часть цифр<br>**DLP:** Блокировка передачи в открытом виде<br>**Аудит:** Audit log всех обращений |
| **Медицинская карта** | Нарушение врачебной тайны, дискриминация, репутационный ущерб, потеря работы | **Хранение:** AES-256, отдельное зашифрованное хранилище<br>**Передача:** TLS 1.2+<br>**Доступ:** ABAC (роль, специальность, пациент)<br>**История:** Версионирование изменений<br>**Резервные копии:** Зашифрованные бэкапы<br>**Аудит:** Audit log всех обращений<br>**Обезличивание:** Анонимизация для аналитики |
| **Результаты анализов** | Нарушение врачебной тайны, дискриминация, репутационный ущерб, потеря работы | **Хранение:** AES-256, отдельное зашифрованное хранилище<br>**Передача:** TLS 1.2+<br>**Доступ:** RBAC (только врач и пациент)<br>**Логирование:** Audit log всех обращений<br>**Контроль целостности:** Цифровая подпись для верификации |
| **Диагноз** | Нарушение врачебной тайны, дискриминация, репутационный ущерб, потеря работы | **Хранение:** AES-256 в БД, Field-level encryption<br>**Передача:** TLS 1.2+<br>**Доступ:** ABAC по специальности врача<br>**История:** Версионирование изменений<br>**Согласие:** Отдельное согласие на раскрытие диагноза третьим сторонам<br>**Обезличивание:** Анонимизация для аналитики |
| **Банковские реквизиты** | Финансовое мошенничество, кража денег | **Хранение:** AES-256, отдельное зашифрованное хранилище<br>**Передача:** TLS 1.2+<br>**Доступ:** Только платежная система, не видна врачам<br>**PCI-DSS:** Сертифицированный платежный шлюз<br>**DLP:** Блокировка передачи банковских реквизитов в открытом виде<br>**Маскирование:** Показывать только часть цифр<br>**Логирование:** Audit log всех обращений |

## Важные данные

| Категория данных | В чём необходимость защиты | Инструменты защиты |
|-|-|-|
| **ФИО пациента** | Идентификационное мошенничество, потеря доверия, потеря клиентов | **Хранение:** AES-256 в БД, Field-level encryption<br>**Передача:** TLS 1.2+<br>**Доступ:** RBAC (только врач и пациент)<br>**Маскирование:** В порталах показывать только инициалы<br>**Логирование:** Audit log всех обращений<br>**Data minimization:** В API передавать только patient_id, не ФИО |
| **Телефон пациента** | Идентификационное мошенничество, фишинг, спам | **Хранение:** AES-256 в БД, Field-level encryption<br>**Передача:** TLS 1.2+<br>**Маскирование:** Показывать только часть цифр<br>**DLP:** Блокировка отправки телефонов внешним сторонам<br>**Согласие:** Отдельное согласие на отправку уведомлений |
| **Email пациента** | Идентификационное мошенничество, фишинг, спам | **Хранение:** AES-256 в БД, Field-level encryption<br>**Передача:** TLS 1.2+<br>**Маскирование:** Показывать только часть букв<br>**DLP:** Блокировка отправки почты в открытом виде |
| **Адрес проживания / Место работы / мето учёбы** | Физическая безопасность, социальная инженерия | **Шифрование:** AES-256<br>**Передача:** TLS 1.2+<br>**Доступ:** RBAC (только HR)<br>**Data minimization:** Собирать только при необходимости<br>**Обезличивание:** Анонимизация для аналитики |
| **Дата рождения** | Идентификационное мошенничество, кража личности, дискриминация по возрасту | **Шифрование:** AES-256 в БД, Field-level encryption<br>**Доступ:** RBAC (только врач и пациент)<br>**Удаление:** Автоматически через 5 лет<br>**Маскирование:** Показывать только возраст (полных лет)<br> |
| **Данные о сотрудниках** | Утечка HR информации, дискриминация | **Хранение:** AES-256 в отдельной системе (не с пациентами)<br>**Передача:** TLS 1.2+<br>**Доступ:** RBAC (только HR и руководство)<br>**Логирование:** Audit log всех обращений<br>**Удаление:** Спустя 5 лет после увольнения |
| **История платежей** | Финансовое мошенничество, аудит, социальная инженерия | **Хранение:** AES-256, отдельное зашифрованное хранилище<br>**Передача:** TLS 1.2+<br>**Доступ:** RBAC (только кассиры и бухгалтерия)<br>**Логирование:** Audit log всех обращений<br>**Обезличивание:** Анонимизация для аналитики |
| **История посещений** | Потеря доверия, потеря клиентов | **Хранение:** AES-256 в БД, Field-level encryption<br>**Передача:** TLS 1.2+<br>**Доступ:** RBAC (только врач и пациент)<br>**Обезличивание:** Анонимизация для аналитики |
| **Audit logs** | Сокрытие инцидентов | **Хранение:** Неизменяемые логи<br>**Передача:** TLS 1.2+<br>**Резервные копии:** Зашифрованные бэкапы<br>**Аудит:** Audit log всех обращений |
